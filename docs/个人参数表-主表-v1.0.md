## 三、交易与行为纪律参数

| 参数 | 签署值 | 框架依据 |
|---|---|---|
| 个股止损 | 跌破预设止损位 → 无条件减半 + 48 小时复评；成本价 -20% → 强制重审 | 6.1 |
| 组合回撤阶梯 | -15% 冻结加仓+复盘；-20% 权益降回目标下限；-30% 防守底仓（权益≤30%、仅留评分≥80）+停手一月 | 6.1 |

| 证伪纪律 | 核心假设单季 ❌ → 无条件清仓；连续两季 ⚠️ → 至少减半；三季 ⚠️ → 清仓；禁止换故事续命 | 7.2 |
| 复盘义务 | 月/季/年三级复盘 + 每笔交易与每条意见 90 天回看；逾期 → 冻结新开仓与加仓 | 7.1、10.3 |
