# Token 成本优化方案（架构分析）

| 文档信息 | 内容 |
|---|---|
| 版本 | v1.0（2026-07） |
| 性质 | 架构优化分析 + 已落地机制说明 |
| 约束 | **零质量降级**：判定由确定性规则引擎执行（A1），全部优化只作用于取证的"方式/时机/深度"，不改变任何判定条件、阈值或框架条款；防守方向不变（A2/A5 完整保留） |

## 一、成本结构（基线：标准档首轮 ≈4.5–7M token）

| 成本项 | 占比 | 根因 |
|---|---|---|
| S3 五项否决取证（24 只 × 5 项代理） | ~35% | 每子项一个代理任务 + 防幻觉链重试 |
| S4 八维取证（10 只 × 定性维+情景装配） | ~35% | 定性维尽调级代理 + ≥2 源佐证 |
| 主循环编排上下文 | ~15% | 产物回读进主上下文 |
| S1 行业/市况代理研究 | ~10% | 宏观/政策/动能非结构化 |
| 降级研究惩罚（无直连时 web-research 代理） | ×1.5–2 全局系数 | 网关 403 时以搜索代替结构化 API |

**关键观察**：判定本身零 token（规则引擎）；token 全部花在"把世界变成证据对象"。因此优化空间 = 让证据尽可能来自结构化源、只在能改变判定结果时才取证、取证时用最便宜的档位。

## 二、优化杠杆（按节约量排序，逐条给出无损性论证）

### L1 结构化优先（adapter-first, agent-fallback）——节约 ~40–50%
凡结构化源可直接给出的字段，禁止派发 LLM 代理：
- **数值子项全部机械化**：现金转化率/应收/摊薄股数 ← EDGAR XBRL companyfacts（已实装）；质押/减持 ← Tushare（已实装）；行情/90日均额/图谱 ← IBKR（**已恢复授权，实测直连**）。
- **半机械化子项**：审计师更换 = 8-K Item 4.01 计数；财报重述 = 8-K Item 4.02 存在性——均可从 EDGAR submissions 的 items 字段机械判定，无需代理。
- LLM 仅保留真正非结构化的：监管事件性质分类、并购/减持语境、定性维初评。
**无损性**：结构化源精度 ≥ LLM 转录（防幻觉链的来源回溯本来就以原文为准）；判定条件不变。

### L2 短路取证（cheap-first gating）——节约 ~15–25%
落地为 `orchestration/forensic_planner.py`：
- **S3**：先跑零成本机械条件 → 任一机械命中即否决短路，**跳过该标的其余全部取证派发**（只归档命中路径）。
- **S4**：先算量化维（机械）→ 分数上界 = 量化分 + 定性维满分；**上界 < 试探线(65) 的标的跳过定性维取证**（结论必然为放弃，取证不可能改变判定）。三情景熊市拦截前置同理。
**无损性**：一票否决语义 = "任一命中即出局"，命中后其余项证据不改变判定（数学短路）；S4 上界剪枝是 branch-and-bound，被剪标的的最终判定（放弃/不推荐）与全量取证完全一致。全部跳过带 skipped 留痕（A4）。

### L3 两阶段升级（screen → confirm）——节约 ~10–15%
非结构化子项先派**抽取档**（成本 ~1/10）做初筛；仅"疑似命中/边缘"升级**尽调档**确认。未命中的以机械勾稽收口。
**无损性**：升级路径保证命中/边缘判定仍由高档确认；初筛漏报方向由防守设计兜底（抽取档存疑一律升级，宁升勿漏）。

### L4 证据缓存与新鲜度复用——增量轮节约 ~50–70%
落地为 `data/evidence_cache.py`：新鲜度窗口内（财务 ≤1 报告期、行情 ≤1 交易日、一致预期 ≤1 月）证据跨期次复用，不重取不重派；**慢变字段**（审计师连任史、IPO/增发史、上市地）单列 365 天窗口。
**无损性**：复用窗口 = 框架 R2.1 已定义的新鲜度窗口，窗口内重取得到的是同一份披露；慢变字段窗口挂 G 级留痕。

### L5 按文档批组取证（doc-grouped batching）——节约 ~10–15%
同一份 10-K 同时服务审计意见、利润率、一次性项等多个子项——取证任务按**源文档**分组而非按子项，一次文档上下文服务多字段抽取。planner 输出 doc_group 字段，执行器合并派发。
**无损性**：字段集合与校验链不变，只减少重复的文档上下文装载。

### L6 档位路由强化 + 用量护栏
- 双档路由已实装（尽调/抽取，FR-A-04）；本方案把**抽取档设为缺省**，尽调档需 planner 显式声明理由。
- 补齐任务 10.6 缺口：`agents/meter.py` 逐任务计量 + 月预算告警（超预算暂停扩权类取证、防守类照常——A5 精神）。

### L7 主循环瘦身
- 代理产物经 StructuredOutput 紧凑 JSON 回传（已实装）；主循环只读判定所需字段，全文归档进快照不进上下文。
- 编排用 pipeline 无阻塞流水（避免慢任务拖着快任务的上下文重复）。

## 三、优化后成本预估

| 场景 | 基线 | 优化后 | 节约 |
|---|---|---|---|
| 首轮全管道（S1→S5，24 候选/10 评分） | 4.5–7M | **1.2–2.2M** | ~65–70% |
| 后续月度增量轮 | 1.5–3M | **0.4–0.9M** | ~70% |
| S4→S5 单段（10 只） | 1.5–2.5M | **0.5–1.0M** | ~60% |

前提：生产网络直连（EDGAR/FRED/Tushare token 配好）+ IBKR 已授权（已确认）。仍在 403 降级环境则各数字 ×1.5–2。

## 四、质量保全清单（逐条对框架）

| 优化 | 框架条款 | 保全方式 |
|---|---|---|
| 短路取证 | 3.2 一票否决 | 命中路径完整归档；跳过项留痕"否决短路"；重审需新证据条款不变 |
| S4 上界剪枝 | 3.4 判定线 | 被剪标的判定=放弃，与全量取证结果恒等；剪枝留痕 |
| 证据复用 | R2.1 新鲜度 | 复用窗口=框架窗口；STALE 照旧视同缺失 |
| 抽取档初筛 | FR-A-02 防幻觉 | 四段校验链对两档一视同仁；存疑必升级 |
| 结构化优先 | A1/A2 | 判定字段仍由规则引擎重算；缺数据照旧产 Gap 不插值 |

**不做的"优化"**（会降质量，明确排除）：降低 ≥2 源佐证要求；跳过防幻觉链任一段；用模型记忆代替取证；放宽新鲜度窗口；抽样式否决审查。

*本方案的可执行机制已落地为代码（forensic_planner / s4 bounds / evidence_cache / meter），见对应测试。*
