| 文档信息 | 内容 |

> 选型结论一句话：**默认栈以"已接入的 IBKR 接口 + 免费权威源（交易所披露/SEC EDGAR/AkShare/FRED）+ 自建数据资产"为主，可零订阅费跑通首轮扫描**；一致预期与行业咨询数据是仅有的两个付费升级决策点，缺失时按框架 CP-9 降级（计低档/不出推荐），不影响系统合规运行。

## 一、选型原则（从框架条文推导）

1. **可溯源**【F 总原则 4】：每个数据点必须能标注"来源 + 日期"；无官方或稳定 API 出处的渠道（自媒体、群消息）一律不入栈。
2. **新鲜度达标**【F 3.5-2】：财务 ≤1 个报告期、价格估值 ≤1 个交易日、一致预期 ≤1 个月；选源时以"能否稳定满足新鲜度"为硬条件。
3. **覆盖率透明**：每个数据域必须写明分市场覆盖率；覆盖不到的部分明确降级行为（框架 3.1/3.2/3.3 的缺失条款），**不允许静默补估**。
4. **主源 + 备源 + 降级**：每域一个主源、至少一个备源；两源读数冲突取更保守值并标注分歧【F M12 执行规则】。
5. **成本分级**：免费/已接入源优先；付费源仅在"该字段无免费替代且影响核心判定"时列为升级决策点，由用户决定订阅。
6. **权威优先**：财报、审计意见、监管处罚等否决项证据必须来自披露义务渠道（交易所/SEC），不用二手转载。

### D3 一致预期（唯一的核心付费决策点）

### D6 产业链与主题图谱

**主源：IBKR 主题图谱接口（已实测 ✅）**——`search_investment_topics`（主题检索，实测返回 AI Infrastructure/AI Chips 等）、`get_company_themes`（公司→主题→同链公司排名，实测 NVDA 返回加速计算/AI 基础设施/AI 芯片/数据中心/生成式 AI 五主题及各主题 75 家关联公司）、`get_company_connections`（竞争对手/产品/地域）。
**额外价值（实测确认）**：主题证据文本含**新鲜定量数据**（如头部云厂商季度 capex 金额、AI 收入占比、在手订单/backlog 规模、HBM 占 DRAM 收入比例），可直接作为 2.2 关键跟踪指标与 3.3 打分的辅助证据（标注来源为"IBKR 主题证据"，关键数字须回溯到财报原文二次确认后方可用于否决项与评分——G，落实权威优先原则）。
**用途**：3.5-1 候选来源③（产业链图谱扩展）；4.3 主题穿透映射表的初始构建（AI 算力链穿透判定）。备源：自建映射表（D10，季度复盘时人工修订）。

## 四、覆盖率评估与降级声明（按框架 CP-9：宁缺毋滥）

| 缺口 | 影响范围 | 降级行为（框架条款） |
|---|---|---|
| A 股中小盘一致预期缺失（免费源下约 60% 个股无覆盖） | 3.1 盈利动能因子、3.3 估值维交叉验证 | 因子/分项按低档或 0 分计并标注【F 3.1/3.3】；**不会**导致系统给出错误方向的意见，只会让缺数据的标的更难入选（保守偏差，方向安全） |
| 指引兑现率冷启动（前 4 季度） | 3.3 管理层维 | 见 D10 冷启动策略，待签署 |
| A 股非陆股通小盘在 IBKR 无行情 | D1 | 走 AkShare 主源，IBKR 仅校验陆股通部分 |
| 美股无质押率字段 | 3.2 否决项 3 | 以 Form 4 减持记录单独判定，标注口径差异（O-03） |
| HBM/光模块第三方量价数据未订阅 | 7.1 月度跟踪 | 用龙头财报季度数据替代（频率降为季度），月度复盘标注"低频代理" |
| 部分电话会纪要无官方文本 | 7.1 季度精读 | 以公司 IR 音频/演示材料为准；第三方转录标注"非官方"且不得作为否决项证据 |

**总覆盖结论**：美股大中盘全字段覆盖率高；A 股大中盘除一致预期外全覆盖；A 股小盘在一致预期与研报密度两项系统性缺失——按框架规则这类标的天然更难通过漏斗，与"小盘 ≤5% 仓位上限"的保守取向一致，无需特殊处理。
