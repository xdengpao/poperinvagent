# poperinvagent — 框架约束型智能投资助手设计

本仓库包含一个基于《AI时代股票投资指导框架》的智能投资助手**设计方案**（产品级 / 系统级 / 流程级，非代码实现）。

**两大目标**（v2.0 起）：
1. **AI 时代投资增长**：以纪律化流程追求长期资本增值；
2. **规则与数据驱动的股票推荐**：系统依据框架的筛选、评分、估值与风控规则，基于可验证数据，生成具体标的推荐与买入/卖出/加仓/减仓/持有意见。

## 核心设计要点

- **规则可回溯，数据可验证**：一切推荐与意见 = 框架条文 + 带来源与日期的数据证据；无数据不出意见（宁缺毋滥）。
- **人机分权**：系统扫描、打分、生成意见；用户复核签认、最终决定与执行；系统不代执行任何交易。
- **只严不松**：全部参数只可向更严方向调整；红线不可配置；意见质量连续四季跑输基准 → 系统自动收紧判定线。

> 声明：本仓库全部内容用于教育与研究。系统的推荐与意见为规则运算结果，不构成收益承诺；按框架操作仍可能亏损大部分本金，投资决策由用户独立作出，盈亏自负。
