# poperinvagent — 框架约束型智能投资助手设计

本仓库包含一个基于《AI时代股票投资指导框架》v1.0 的智能投资助手**设计方案**（产品级 / 系统级 / 流程级，非代码实现）。该助手的核心定位是框架的"运行时与守门人"：防止惰性、情绪化判断与主观偏好干扰投资流程，强制用户按框架完成研究、决策、记录、复盘与风控。

## 阅读顺序建议

1. 设计方案第二章（对框架的理解复述与问题标注）——含框架内部 10 处冲突、20 余处未定义项的登记，以及"哪些设计可继续、哪些必须等待用户补充"的判定；
2. 第五、六章（系统模块与工作流程状态机 S0-S12）；
3. 第十四章（示例交互，展示助手如何约束用户）。
